Important notice

This document lists third-party open-source software packages included in the SquadGoo mobile application build, based on direct production dependencies declared in the app package manifest at the time of this version.

It is provided for transparency and licence attribution. Licence texts remain governed by each package's own licence file. Transitive (nested) dependencies are also present in the release binary; the authoritative machine-readable inventory is maintained with each store build (package lock / licence scan).

How to read this list

  • Package — npm package name
  • Version — version resolved for this notices snapshot
  • Licence — licence identifier declared by the package author (SPDX-style where available)

Common licence families used below include MIT, Apache-2.0, and dual MIT/Apache-2.0. Full licence texts are available in each package's repository or node_modules/<package>/LICENSE in the development tree.
